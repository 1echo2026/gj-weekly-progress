# 销售直推业绩看板

单文件、纯前端的销售直推业绩数透看板。导入订单池业绩与销售名单，自动按姓名数透直推业绩并匹配回名单，支持特殊经理的「架构调整」人工汇总。

## 数据源

1. **飞书多维表格（默认）**：登录后经 Cloudflare Worker 代理读取，每 60 秒自动同步。接入步骤见 [飞书数据库接入说明.md](飞书数据库接入说明.md)。
2. **本地文件**：登录页点「本地文件模式」，或登录后点「本地文件」，手动上传 Excel / CSV。

## 功能

- 导入订单池与销售名单（.xlsx / .xls / .csv，可拖拽）
- 自动识别列名并做字段映射（可手动调整）
- 按姓名数透直推业绩，匹配回名单并追加「直推业绩」列，计算达成率
- 架构调整：特殊经理无法直接数透时，勾选其名下一线销售求和
- 一键导出 CSV / Excel
- 数据仅在本地浏览器内处理，不上传服务器

## 使用

直接用浏览器打开 `index.html`，或部署到任意静态托管。右上角「载入示例数据」可快速体验。

## 技术

- 原生 HTML / CSS / JavaScript，无构建依赖
- [SheetJS](https://sheetjs.com/) 解析 Excel / CSV
- 办公配色：深藏青 + 白 + 克制蓝点缀
