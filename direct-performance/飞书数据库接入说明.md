# 飞书多维表格接入说明

看板已支持从飞书多维表格实时同步数据。架构如下：

```
浏览器（GitHub Pages 静态页）
        │  登录后带 Bearer Token
        ▼
Cloudflare Worker（持有飞书 app_secret，做鉴权与代理）
        │  飞书 Open API
        ▼
飞书多维表格（订单池表 + 销售名单表）
```

`app_secret` 只存在 Worker 的环境变量里，绝不进入前端代码。

## 一、飞书侧准备

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，创建「企业自建应用」。
2. 在「凭证与基础信息」记下 **App ID** 和 **App Secret**。
3. 在「权限管理」开通多维表格权限：`bitable:app`（读写）或 `bitable:app:readonly`（只读，推荐）。
4. 创建版本并发布，等待企业管理员审批通过。
5. 打开你的多维表格，右上角「⋯」→「添加文档应用」，把该应用加为**可查看**协作者。否则接口会报 `permission denied`。
6. 从多维表格地址取参数：

```
https://xxx.feishu.cn/base/{APP_TOKEN}?table={TABLE_ID}&view=xxx
```

1. `APP_TOKEN` 是 `/base/` 后面那段。
2. `TABLE_ID` 是 `?table=` 后面那段，每张表不同。
3. 需要两张表：**订单池**（含姓名、业绩金额）、**销售名单**（含基地、姓名、目标、类别）。

## 二、部署 Cloudflare Worker

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com/)，进入 Workers & Pages → 创建 Worker。
2. 把 `api/worker.js` 的全部内容粘贴进去，部署。
3. 在 Worker 的 Settings → Variables and Secrets 添加以下变量（敏感项选 Secret）：

| 变量名 | 说明 | 示例 |
|---|---|---|
| `FEISHU_APP_ID` | 飞书应用 App ID | `cli_xxx` |
| `FEISHU_APP_SECRET` | 飞书应用 App Secret | `xxx` |
| `BITABLE_APP_TOKEN` | 多维表格 app_token | `basbcnxxx` |
| `ORDERS_TABLE_ID` | 订单池表 table_id | `tblxxx` |
| `STAFF_TABLE_ID` | 销售名单表 table_id | `tblxxx` |
| `LOGIN_USER` | 看板登录账号 | `admin` |
| `LOGIN_PASSWORD` | 看板登录密码 | 自定强密码 |
| `SESSION_SECRET` | 令牌签名密钥 | 随机长字符串 |
| `ALLOWED_ORIGIN` | 允许的前端来源 | `https://1echo2026.github.io` |

4. 记下 Worker 地址，如 `https://xxx.workers.dev`。
5. 自测：浏览器打开 `https://xxx.workers.dev/api/health`，应返回 `{"ok":true,...}`。

## 三、配置前端

1. 打开看板页面，登录页点「设置数据接口地址」，填入 Worker 地址并保存。
2. 用 `LOGIN_USER` / `LOGIN_PASSWORD` 登录。
3. 登录后自动拉取数据，每 60 秒自动同步一次；顶部可手动「刷新」。

## 四、安全说明

1. 数据不进入 GitHub 仓库，只有登录后经 Worker 返回。
2. 页面本身公开，但 `/api/data` 必须携带有效令牌，密码校验在 Worker 完成。
3. 建议 `ALLOWED_ORIGIN` 精确填 Pages 域名，避免其他站点调用。
4. 如需更强保护：改用飞书 OAuth 登录（仅企业成员可进），或把仓库与托管迁到私有环境。
5. 登录接口目前无频率限制，如需可加 Cloudflare Rate Limiting。

## 五、常见问题

1. `飞书鉴权失败 10003`：App ID / Secret 填错，或应用未发布。
2. `飞书接口错误 91403`：应用没有该多维表格权限，回到第一步第 5 条添加协作者。
3. `permission denied`：同上，确认应用可查看该 Base。
4. 前端提示同步失败：检查 Worker 地址、`ALLOWED_ORIGIN` 是否包含页面域名。
5. 表格字段没识别：页面「字段映射」里手动选择对应列即可。
